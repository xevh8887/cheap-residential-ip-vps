## 先分清三种都叫“便宜”的 IP

WePC 的套餐描述里同时出现原生 IP、家宽、双ISP 三个词，价格却从 AUD$10.90 到 AUD$49.90 拉开四倍多，容易看花眼。

原生 IP 指的是 IP 注册地和机房所在地一致。一台放在洛杉矶的机器，WHOIS 查出来是美国 IP，这就叫原生。原生只解决“地区对不对”的问题，不解决“像不像真人”。

家宽 IP 的要求更进一步：这个 IP 必须落在住宅宽带地址段里，归属的 ASN 是当地民用宽带运营商，而不是机房运营商。平台风控系统查 IP 时看的正是这一层，机房段会被直接标成数据中心流量。

双ISP 说的是同一个 IP 在两个不同的民用 ISP 名下都有注册记录。它的用处是分散风险：其中一个 ISP 的段被平台批量标记时，另一个段还有记录可用。

这三层是叠加关系，不是替代关系。WePC 表里那两款 AUD$10.90 的产品，英国那款标题写的是“英国普通原生IP”，S9 的整理里也明确标注“非家宽IP”；德国那款写的是“德国原生IPv4+IPv6”，同样没有家宽字样。它们便宜是因为只做到了第一层。

想买家宽，起价就是 AUD$12.90。这 2 澳元的差价，买的正是地址段属性。

## 中转线路是另一笔账，倍率会吃掉流量

WePC 除了各地 VPS，还单独卖一条“视频及直播专用中转线路”，AUD$29.90/月，含 500GB 流量和 3 个中转。

这条线的计价方式和普通 VPS 不一样：流量按倍率扣。深港 IEPL 线路是 4 倍率，建议电信用户走；海外优化线路是 2 倍率，建议移动用户走。另外还有 5 倍率的线路。

也就是说，500GB 的额度在 4 倍率线路上，实际能跑的流量只有标注的四分之一。直播中转的流量消耗本来就大，倍率叠加之后，500GB 撑不了多久。这条线还明确写了**不支持联通用户**。

买之前先确认自己需要哪条线路、对应倍率多少，再倒推流量够不够用。看到“500GB”就按 500GB 估算，会严重低估成本。

## 下单前要确认的五件事

**内存只有 512M。** 全表所有方案的内存都是 512M，日本直播那款是 786M。这个配置跑 Linux 加轻量面板没问题，装 Windows 不现实。要跑重一点的服务，得自己在系统里加 swap 或者换方案。

**硬盘只有 10G。** 系统装完剩不下多少空间，存素材、跑批量任务要另配存储，别指望机器本身。

**流量是双向计算。** 表里写的 1.5TB、2TB 都是双向流量，上传下载加一起算。直播推流是持续上行，消耗比想象中快。

**结算货币是澳元。** 用支付宝付款时按当天汇率折算成人民币扣款；用 PayPal 要先在注册时把账户货币选成 AUD。

**地区决定线路，线路决定体验。** 同样 AUD$19.90，日本那款是无优化家宽、澳大利亚墨尔本那款是三网回程优化，体验差得远。价格一样不代表能互换。
